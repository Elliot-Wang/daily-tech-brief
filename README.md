# Daily Tech Brief

每日中文 AI、科技产业与金融市场简报。

## 阅读

GitHub Pages 阅读器：

- https://elliot-wang.github.io/daily-tech-brief/
- 指定日期可用 hash 直接打开，例如：`https://elliot-wang.github.io/daily-tech-brief/#2026-09-15`

网页会自动读取仓库中的日报归档，新增 Markdown 后无需额外维护索引。

## 内容范围

- **AI**：前沿模型、Agent、OpenAI、Anthropic、Google DeepMind、DeepSeek、Qwen、Kimi 等
- **科技产业**：芯片、云、数据中心、供应链、大型科技公司、M&A、监管与平台变化
- **金融与市场**：AI/科技相关股票、IPO、融资、财报、估值、资本开支、利率与宏观变化
- **软件工程**：只收录真正重要的架构、数据库、开发工具与工程实践变化

## 文件结构

```text
briefs/YYYY/MM/YYYY-MM-DD.md
```

每篇通常包含：

1. 执行摘要
2. 当日最重要的 5 条新闻
3. 每条新闻的事实、重要性与短评
4. 值得阅读的论文 / 技术或商业文章
5. 一段趋势深度解读

仓库由自动任务每日更新。
