# Daily Tech Brief

Daily Chinese technology brief focused on:

- AI: models, agents, OpenAI, coding agents
- Engineering: Java, backend architecture, distributed systems, databases, developer tooling
- Tech industry: major developments that materially affect the areas above

## Structure

Daily briefs are stored as:

```text
briefs/YYYY/MM/YYYY-MM-DD.md
```

Each brief contains:

1. Executive summary
2. Five most important news items
3. Short analysis for each item
4. Recommended papers / technical blogs
5. One deeper trend analysis

The repository is updated automatically once per day.
